# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Next.js App Router with TypeScript, Tailwind CSS, `@xyflow/react`, Zustand, Lucide icons, and a Gemini-backed API layer.

## Users

Developers and product builders who have an application idea but need to turn it into an implementation-ready product specification and an ordered workflow for an AI coding agent.

## Product Purpose

CodeWithAI turns a raw app idea into adaptive product questions, a dependency-aware implementation canvas, and a downloadable `prd.md`. Success means a user can clarify an idea, understand the build sequence, hand the PRD to a coding agent, and watch task status update live.

## Positioning

The product joins product discovery, implementation planning, a portable PRD, and CLI-driven build telemetry in one continuous browser workflow.

## Operating Context

Users begin on the web with a short idea prompt, answer three to five generated questions, review an interactive workflow graph, export a PRD, and then use that PRD with tools such as Cursor, Claude Code, Antigravity, or Roo Code. A companion CLI reports agent progress back to the open canvas.

## Capabilities and Constraints

- Adaptive single- and multi-select questionnaires generated by `/api/ai/questions`.
- Workflow synthesis through `/api/ai/workflow` with dependency nodes, phases, acceptance criteria, CLI commands, and four statuses: pending, in progress, done, and blocked.
- Full-screen pan-and-zoom canvas with controls, minimap, status filtering, and node inspection.
- PRD generation, preview, clipboard copy, and direct `prd.md` download.
- Live session updates over server-sent events with lightweight polling fallback.
- Backend, Gemini integration, persistence, APIs, and companion CLI are owned by Agent 2; the frontend integrates through the documented contracts.

## Brand Commitments

The product name is CodeWithAI. Voice should be direct, encouraging, technically credible, and useful to both Indonesian and international builders; current product UI copy is English for consistency with developer tooling.

## Evidence on Hand

The repository contains product architecture, API contracts, and role-specific job sheets under `agent/`. There are no customer claims, testimonials, production metrics, logos, or photographic assets; future work must not fabricate them.

## Product Principles

- Turn ambiguity into concrete decisions one step at a time.
- Make dependencies and current progress legible at a glance.
- Keep every generated artifact portable beyond this application.
- Show system state honestly, including loading, errors, blocked work, and disconnected telemetry.
- Preserve a fast path from idea to an actionable build plan.

## Accessibility & Inclusion

The web interface must remain keyboard navigable, responsive, readable with strong contrast, respectful of reduced-motion preferences, and must not communicate status by color alone.
